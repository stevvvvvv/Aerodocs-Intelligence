# AeroDocs Intelligence : démo

Assistant RAG pour la documentation technique aéronautique : réponses citées (document, version, page), refus quand les sources sont insuffisantes, détection de contradictions, gestion des versions.

Démo en lecture seule sur un corpus **fictif**. Sans clé API, les réponses sont extractives : ce sont des phrases sources citées, sans génération. Le code source, l'évaluation et les instructions d'installation sont sur GitHub.
